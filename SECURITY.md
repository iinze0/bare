# Security

bare does not ask for your Microsoft password. It does not fetch code at runtime.

Options 19 and 20 can disable updates or real-time scanning. They are off unless ticked, and apply asks again. Do not tick them on a PC you use for banking or mail.

If `bare.ps1` writes outside documented services, schtasks, powercfg, AppX, winget, or the registry keys in [Help/Options.md](Help/Options.md), open an issue.

Run the copy on `main`, not a repost.
