# Security

bare does not ask for your Microsoft password. It does not fetch code at runtime.

Options 19 and 20 can disable updates or real-time scanning. They are off unless ticked, and apply asks again. `r` tries to turn Defender real-time back on.

Run the files attached to [v2.6](https://github.com/iinze0/bare/releases/tag/v2.6), or the copy on `main`.
