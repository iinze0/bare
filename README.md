# bare

Pick-list Windows debloat and performance tool. Tick options. Nothing changes until you apply.

Made by [iinze0](https://github.com/iinze0). MIT. Not affiliated with Talon or QuakedK.

| | |
| --- | --- |
| Version | 2.4 |
| OS | Windows 10 and 11 |
| Run | `bare.bat` as administrator, same folder as `bare.ps1` |
| Log | `bare-log.txt` next to the script |
| Network | None, unless you tick OneDrive or the browser swap |

# Important

Presets only tick boxes. `a` applies them. Edge, IPv6, OneDrive, Windows Update, Defender, and idle-off ask for `yes` again.

# Usage

1. Download the repo zip. Do not pipe it into `iex`.
2. Right-click `bare.bat` and run as administrator.
3. Type a number to toggle. `p`, `g`, or `v` fills a preset.
4. Type `a`. Restart.
