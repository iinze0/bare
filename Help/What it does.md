# What bare does

See also [Browser.md](Browser.md) and [Privacy.md](Privacy.md).

Option 1 performance: inbox apps, ads, tasks, quiet services disabled, CPU 100% on AC, Game DVR off, Game Mode on. Edge stays.

Option 2 gaming: same, but Bluetooth, audio, and Xbox services automatic. Edge stays.

Option 3: performance plus CPU idle off.

Option 6 privacy: ads, activity history, advertising id, location, Bing search, telemetry 0, then optional browser swap.

Option 7: winget Firefox or Brave, then optional Edge uninstall.

Option 4 scan. Option 5 re-applies the saved profile.
