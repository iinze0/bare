# Privacy profile

Option 6 is the privacy pass. It is not the gaming pass.

It applies the inbox-app removal, ads, and task disables, then:

- AllowTelemetry 0
- Advertising ID off
- Activity history, publish, and upload off
- Location policy off
- Bing web search and Cortana off
- Settings sync off
- Consumer suggestions off
- Search and telemetry services disabled

It then asks if you want Firefox or Brave, and only then offers Edge removal.

Defender and Windows Update stay on. A privacy pass that disables updates leaves the machine open. OneDrive is not uninstalled. Sign-in is not removed.
