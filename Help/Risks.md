# Risks

These are the unstable parts, in order.

- Hardware-accelerated GPU scheduling can stutter on older drivers. Turn it off in Graphics settings if a game gets worse.
- SystemResponsiveness 0 gives less CPU reserve to background audio. If voice chat crackles, that is the first thing to undo.
- Search disabled on the performance profile makes file search slow.
- Xbox services disabled on the performance profile breaks Game Bar sign-in. Use the gaming profile if you need that.
- Idle off (option 3) raises heat and can drop frames once the CPU thermal-limits. Do not use it on a laptop.
- A restore point can fail on systems with System Restore turned off. The log says `Restore point skipped` when that happens.
- Removed Store apps do not come back from System Restore in every Windows build. Reinstall from the Store if you want one back.
