# Risks

- Option 10 idle off raises heat. Skip it on a laptop.
- Option 11 HAGS can stutter on old GPU drivers. Turn it off in Graphics settings if a game gets worse.
- Option 6 kills indexed file search.
- Option 7 breaks Xbox sign-in and Game Bar cloud saves.
- Option 14 drops Bluetooth controllers and headphones.
- Option 15 stops printing.
- Option 16 can break a VPN or an ISP that still needs IPv6.
- Option 17 removes OneDrive and its sync. Files already downloaded stay on disk.
- Option 18 can break Widgets.
- Option 19 stops security patches until you set wuauserv back to Manual or Automatic.
- Option 20 turns off real-time scanning if Tamper Protection allows it. The PC will not scan new files. Not recommended.
- Restore point creation can fail. The log says `Restore point skipped` when it does.
- Removed Store apps do not always return with System Restore. Reinstall them from the Store.
