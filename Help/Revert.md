# Revert

Option 1 creates a restore point named `bare before changes` when System Restore is available.

1. Open Start and search for Create a restore point.
2. System Restore, then choose `bare before changes`.
3. Restart.

That puts services, tasks, and policies back. Apps that were removed stay removed until you reinstall them from the Store.

The log next to the script is `bare-log.txt`. It lists each service and app the last pass touched.
